# Dr. Rodas Museum

A new donation-first website for the **Dr. Rodas Museum Project** — a major initiative of Dr. Rodas Foundation (https://drrodas.org).

Structure based on a clean-water fundraising site model (hero donation widget, transparency/proof flow, impact counters, ways to support), fully rebranded with the foundation's official identity: navy #0B1239 / gold #A77C2C / ivory, official logo, and official published content only.

- Tagline: *Preserving Heritage. Advancing Knowledge. Inspiring Generations.*
- Six proposed exhibition & research areas, all stages Planned
- Payments are disabled in preview — demo donations record as PENDING and progress counts confirmed donations only
- Contact: support@drrodas.org

Static site: `index.html` + `logo.png`, no build step.
